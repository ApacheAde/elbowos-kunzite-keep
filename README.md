# Kunzite Keep

Full-colour Python 3 neon tower-lite arcade for [ElbowOS](https://x.com/ElbowOS).

Plant short-lived kunzite crystals on a 4×3 grid.
They fire cyan bolts up their lane.
Rose grunts, mint runners and gold tanks march the keep.
A / D pick a lane. W / S pick a row. Space plants (costs energy).

## Play

```
pip install -r requirements.txt
python3 kunzite_keep.py --play
```

## Record a 9:16 reel

```
python3 kunzite_keep.py --record
```

Writes a 1080×1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
